# AgentMascot source assets

This directory stores development source images for future mascot frame work.
Runtime frames are still kept under `src/assets/<mascot>/frames/` and imported
explicitly by `src/mascot/assets.js`.

- `nailong/hd-source/`: high-resolution generated source frames.
- `nailong/original-hd-source/`: high-resolution source frames closer to the
  original Nailong appearance.
- `kurisu/frames-preview-clean.png`: contact sheet preview for the current
  Kurisu frame set. The transparent runtime frames are committed in
  `src/assets/kurisu/frames/`.
